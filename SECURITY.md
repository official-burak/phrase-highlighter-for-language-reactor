# Security Policy

## Supported versions

Please report vulnerabilities against the latest code on `main`.

## Reporting a vulnerability

Do not open a public GitHub issue for security reports.

Report privately using one of these channels:

- GitHub private vulnerability reporting on this repository (Security tab, then Advisories)
- Email: [official.burak@icloud.com](mailto:official.burak@icloud.com)

Include a description of the issue, steps to reproduce, and the impact if you know it. I will acknowledge the report and follow up with a fix or next steps.
