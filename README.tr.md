# Phrase Highlighter for Language Reactor

[English](README.md) | **Türkçe** | [Español](README.es.md) | [简体中文](README.zh-Hans.md) | [Русский](README.ru.md)

[Language Reactor](https://www.languagereactor.com) ile dil çalışanlar için bir Chrome eklentisi. Yalnızca languagereactor.com'da çalışır. youtube.com veya netflix.com'da çalışmaz.

Bir ders aç, sonra Phrase Highlighter simgesine tıkla (Language Reactor çubuğundaki ilk düğme). Sağda kenar çubuğu açılır. Kartlar o anki satırın kalıplarını gösterir, tüm videoyu veya kitabı değil. İç içe kalıplar ikisi de çıkar, örneğin `going to be` ve `going to`. Anlamlar Language Reactor'ın sayfadaki kendi sözlüğünden gelir. Language Reactor sitesi yeter. Language Reactor'ın Chrome eklentisine ihtiyacın yok.

## Kurulum

Bu eklenti Chrome Web Store'da yok. GitHub Releases zip'inden yüklenir.

1. [v1.0.0 zip](https://github.com/official-burak/phrase-highlighter-for-language-reactor/releases/download/v1.0.0/phrase-highlighter-for-language-reactor-1.0.0.zip) dosyasını indir.
2. Arşivi aç.
3. Chrome'da `chrome://extensions` sayfasını aç.
4. Geliştirici modunu aç.
5. Load unpacked'e tıkla.
6. `manifest.json` olan klasörü seç.

Güncellemeden sonra o sayfada eklentiyi yenile, sonra languagereactor.com sekmesini yenile.

## Nasıl kullanılır

1. Bu Chrome eklentisini yükle (Kurulum).
2. [languagereactor.com](https://www.languagereactor.com) adresini aç.
3. Bir ders aç (video, kitap, podcast veya metin).
4. Language Reactor araç çubuğundaki Phrase Highlighter simgesine tıkla. Renkliyse kenar çubuğu açıktır. Soluk griyse kapalıdır, yine de tıklayabilirsin. Chrome tercihini hatırlar.
5. O anki satırın kalıp kartlarını oku. Satırda kalıp yoksa kenar çubuğu açık kalır ve eklenti logosunu gösterir. Kalıplar gelince kartlar döner.

## Simge yoksa

**YouTube.com'da neden görünmüyor?**

YouTube'u Language Reactor üzerinden izle, doğrudan youtube.com'da değil.

**Simge kayboldu.**

Bir ders aç. Katalogda, kaydedilenlerde, ayarlarda ve ana sayfada gizlidir.

Yalnızca Language Reactor'da çalışır. Dersini başka sunuculara göndermez. Bu proje Language Reactor veya Dioco ile bağlantılı değildir.
