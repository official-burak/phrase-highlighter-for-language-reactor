# Phrase Highlighter for Language Reactor

[English](README.md) | [Türkçe](README.tr.md) | **Español** | [简体中文](README.zh-Hans.md) | [Русский](README.ru.md)

Una extensión de Chrome para quienes aprenden idiomas con [Language Reactor](https://www.languagereactor.com). Solo funciona en languagereactor.com. No funciona en youtube.com ni en netflix.com.

Abre una lección y pulsa el icono de Phrase Highlighter (el primer botón de la barra de Language Reactor). A la derecha se abre un panel con tarjetas de significado de la línea en la que estás, no de todo el vídeo o el libro. Las frases anidadas aparecen las dos, por ejemplo `going to be` y `going to`. Los significados salen del diccionario de Language Reactor en la página. El sitio de Language Reactor basta. No necesitas la extensión de Chrome de Language Reactor.

## Instalar

Esta extensión no está en Chrome Web Store. Instálala con el zip de GitHub Releases.

1. Descarga el [zip v1.0.0](https://github.com/official-burak/phrase-highlighter-for-language-reactor/releases/download/v1.0.0/phrase-highlighter-for-language-reactor-1.0.0.zip).
2. Descomprímelo.
3. En Chrome, abre `chrome://extensions`.
4. Activa el modo de desarrollador.
5. Pulsa Cargar descomprimida.
6. Elige la carpeta que contiene `manifest.json`.

Después de actualizar, recarga la extensión en esa página y luego la pestaña de languagereactor.com.

## Cómo usarlo

1. Instala esta extensión de Chrome (ver Instalar).
2. Abre [languagereactor.com](https://www.languagereactor.com).
3. Abre una lección (un vídeo, un libro, un podcast o un texto).
4. Pulsa el icono de Phrase Highlighter en la barra de Language Reactor. Si está a color, el panel está abierto. Si está en gris, está cerrado, pero igual puedes pulsarlo. Chrome recuerda tu elección.
5. Lee las tarjetas de la línea actual. Si esa línea no tiene frases, el panel se queda abierto y muestra el logo de la extensión hasta que haya frases.

## Si no ves el icono

**¿Por qué no lo veo en YouTube.com?**

Tienes que verlo a través de Language Reactor, no en youtube.com.

**El icono desapareció.**

Abre una lección. Está oculto en el catálogo, los elementos guardados, los ajustes y la página de inicio.
