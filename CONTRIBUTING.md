## Scope

This extension shows Language Reactor phrase meaning cards for the current line on languagereactor.com. Stay in that lane: no translation UI, playback control, or Language Reactor assets. languagereactor.com only (not youtube.com or netflix.com).

## Sending a patch

If you send a change, run `npm test` before you open a pull request. Load the folder that contains `manifest.json` as an unpacked Chrome extension. Do not commit `node_modules/` or secrets.
